# 🏥 Dokumen Penjelasan Proyek: Pendaftaran Pasien Rumah Sakit Sehat

Sistem pendaftaran pasien berbasis web yang dirancang untuk mendigitalisasi proses registrasi di **Rumah Sakit Sehat**. Sistem ini bertujuan untuk mengurangi antrean fisik, mempercepat pendataan pasien, dan memastikan data tersimpan secara aman dan terstruktur dalam database.

---

## 📌 1. Ringkasan Proyek (Project Overview)
* **Judul Proyek:** Pendaftaran Pasien Rumah Sakit Sehat
* **Jenis Aplikasi:** Web-Based Management System (Sistem Manajemen Berbasis Web)
* **Deskripsi:** Solusi digital untuk mengotomatisasi pendaftaran pasien baru secara cepat, efisien, dan meminimalkan kesalahan input data manual di area resepsionis rumah sakit.

---

## 👤 2. Peran dalam Kelompok (My Role & Responsibilities)
Dalam pengerjaan proyek kolaboratif ini, saya bertanggung jawab penuh pada bagian **Front-End Design & User Experience (UX)** dengan fokus kerja meliputi:

* **Desain Antarmuka (UI):** Merancang dan mengimplementasikan tampilan *Dashboard Utama* yang modern, intuitif, dan profesional agar pasien maupun admin dapat menavigasi sistem dengan mudah.
* **Konsep Visual:** Menggunakan palet warna yang bersih (*clean*) dan profesional seperti kombinasi biru medis dan putih untuk membangun kesan steril, tepercaya, dan ramah pengguna.
* **User Experience (UX) Optimization:** Mengatur tata letak elemen penting seperti tombol *"Pendaftaran Cepat"*, *"Jadwal Dokter"*, dan *"Informasi Layanan"* agar dapat ditemukan oleh pengguna dalam hitungan detik.
* **Estetika & Tipografi:** Menerapkan penggunaan ikon yang konsisten, font yang mudah dibaca, serta pemanfaatan *whitespace* (ruang kosong) yang tepat untuk menghindari kesan penuh atau berantakan.
* **End-to-End System Knowledge:** Menguasai dan memahami seluruh alur fungsionalitas aplikasi pendaftaran ini dari tahap awal (input pasien) hingga tahap akhir (verifikasi oleh admin).

---

## 🛠️ 3. Teknologi yang Digunakan (Tech Stack)
Sistem ini dikembangkan dengan kombinasi teknologi standar industri berikut:
* **Bahasa & Framework:** HTML5, CSS3, JavaScript, dan PHP
* **Framework CSS:** Bootstrap / Tailwind CSS (Memastikan tampilan website sepenuhnya *Responsive* di HP maupun Laptop)
* **Database System:** MySQL / PostgreSQL (Untuk manajemen penyimpanan data pasien dan jadwal dokter)

---

## 🚀 4. Fitur Utama Aplikasi
Website **Rumah Sakit Sehat** dilengkapi dengan fitur-fitur utama sebagai berikut:

1. **Form Pendaftaran Pasien Baru:** Input data diri pasien secara lengkap (Nama, NIK, Alamat, Tanggal Lahir) dengan validasi form.
2. **Pemilihan Poli & Dokter:** Fitur pilihan berkategori (*dropdown* dinamis) untuk memilih poliklinik dan jadwal dokter yang sedang bertugas.
3. **Sistem Antrean Otomatis:** Sistem langsung menghasilkan nomor antrean unik secara otomatis setelah pasien berhasil menyelesaikan pendaftaran.
4. **Dashboard Admin:** Halaman khusus bagi staf rumah sakit untuk melihat, memverifikasi, menyaring, dan mengelola daftar pasien masuk beserta laporan harian.
